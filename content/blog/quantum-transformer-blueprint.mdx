Quantum transformers adapt the attention mechanism by encoding queries, keys, and values as parameterized quantum states. Hybrid
architectures typically process embeddings classically before quantum mixing.

### Architecture sketch

- Photonic encoders prepare squeezed states representing token amplitudes.
- Controlled-phase mixers implement attention weights via interferometer meshes.
- Mid-circuit measurements feed classical post-processing layers.

### Complexity discussion

Hybrid quantum-classical attention achieves polylogarithmic depth in token length for certain structured inputs, but requires
fault-tolerant photonic control for scalability.
