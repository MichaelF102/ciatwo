Quantum kernel methods lift classical data into high-dimensional Hilbert spaces using parameterized feature maps. The induced
kernel can be plugged into support vector machines or Gaussian processes to capture quantum correlations.

## Designing feature maps

A feature map $U_\phi(x)$ should encode task-relevant inductive biases while remaining hardware efficient. Expressivity can be
assessed via the **Fourier spectrum** of the kernel.

<CodeBlock language="python">
{`from qiskit import QuantumCircuit
from qiskit.circuit.library import ZZFeatureMap

num_features = 4
feature_map = ZZFeatureMap(feature_dimension=num_features, reps=2)
print(feature_map.decompose().draw('text'))`}
</CodeBlock>

The overlap $k(x, x') = |\langle 0| U_\phi(x)^{\dagger} U_\phi(x') |0 \rangle|^2$ defines the kernel value. Efficient evaluation
requires depth-aware compilation to minimize two-qubit gate errors.

## Expressivity diagnostics

- **Kernel alignment** with a uniform prior baseline highlights whether the feature map is informative.
- **Eigenvalue spectrum** near rank-deficient regimes indicates overfitting and motivates regularization.
- **Adversarial robustness** testing with randomized smoothings reveals gradient masking artifacts.
